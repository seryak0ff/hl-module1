### 17. Библиотека научных статей


__Задание:__ Реализовать систему скачивания материалов.
* __Статья:__ DOI, название, автор, год публикации.
* __Пользователь:__ логин, университет, подписка (дата окончания).
* __Скачивание:__ связь статьи и пользователя, дата, формат (PDF/HTML).
   * __Дополнительно:__ Выводить активность работы пользователей в системе  
     по месяцам (количество скачиваний каждого формата)
